# Nahang Tunnel Panel

پنل مدیریت تانل برای v2ray با ترنسپورت‌های اختصاصی و Backhaul. این راهنما از صفر تا راه‌اندازی کامل را پوشش می‌دهد.

> ⚠️ فقط روی سرورهایی که مالک یا مجاز به مدیریت آن‌ها هستی استفاده کن.

## ۱. معماری و ایده‌ی کلی

```
کاربر  ──►  سرور ایران (IP:پورت ورودی)  ══ تانل ══►  سرور خارج  ──►  v2ray روی سرور خارج
```

- **سرور ایران:** کاربر به آن وصل می‌شود. نقش آن «سرور» است و پورت تانل را گوش می‌دهد.
- **سرور خارج:** به سرور ایران وصل می‌شود و ترافیک را به v2ray خودش می‌فرستد. نقش آن «کلاینت» است.
- **پنل:** روی هر دو سرور نصب می‌شود. هر تانل روی هر سرور با یک «توکن مشترک» به تانل سرور مقابل وصل می‌شود.

| مورد | توضیح |
|---|---|
| دو سرور لینوکسی | Ubuntu یا Debian با دسترسی `root` (یکی ایران، یکی خارج) |
| آدرس IP عمومی | هر دو سرور باید IP عمومی داشته باشند |

## ۳. نصب روی سرور ایران

### ۳.۱ دانلود و اجرای نصب‌کننده

```bash
curl -fsSL https://raw.githubusercontent.com/Alireza647xvhyfdc/nahangpanel/main/install.sh | sudo bash
```

این دستور نصب‌کننده را از گیت‌هاب می‌گیرد و همان لحظه اجرا می‌کند. باینری پنل هم از Releases همان مخزن دانلود می‌شود. در حین نصب، نصب‌کننده دو چیز را می‌پرسد و پاسخ را در همان خط می‌نویسی: پورت پنل، و IP عمومی خودت (اختیاری). یک پورت بین ۱ تا ۶۵۵۳۵ وارد کن. اگر فقط Enter بزنی، یک پورت تصادفی آزاد انتخاب می‌شود. پورت‌هایی که الان در حال استفاده هستند قبول نمی‌شوند. پورتی را که انتخاب می‌کنی، در پایان نصب نشان داده می‌شود و بعداً هم با منوی `nahang` قابل دیدن است.

اگر IP خودت را وارد کنی، پنل روی IP سرور در آدرس HTTPS باز می‌شود و فقط آن IP می‌تواند وارد شود. اگر خالی بگذاری، پنل فقط از طریق SSH در دسترس است.

### ۳.۳ ذخیره‌ی اطلاعات ورود

در پایان نصب، کاربر، رمز و آدرس نمایش داده می‌شود. **رمز را همان‌جا ذخیره کن.** در هر زمان با منوی `nahang` هم می‌توانی آن را ببینی.

## ۵. ورود به پنل

### اگر IP خودت را وارد کرده‌ای

در مرورگر باز کن:

```
https://SERVER-IP:PANEL_PORT
```

- گواهی خودامضاست، پس مرورگر هشدار می‌دهد. گزینه‌ی **Advanced ← Proceed** را بزن.
- کاربر: `admin`
- رمز: همان رمزی که در پایان نصب دیدی.

### اگر IP را خالی گذاشته‌ای (فقط SSH)

از دستگاه خودت این دستور را اجرا کن و پنجره را باز نگه دار:

```bash
ssh -L PANEL_PORT:127.0.0.1:PANEL_PORT root@SERVER-IP
```

بعد در مرورگر باز کن:

```
http://127.0.0.1:PANEL_PORT
```

> `PANEL_PORT` همان پورتی است که هنگام نصب انتخاب کردی. هر دو جای آن را با همان عدد عوض کن.

## ۶. ساخت تانل

این بخش را اول روی **سرور ایران** انجام بده.

### ۶.۱ ساخت تانل روی سرور ایران

1. در پنل، از منوی سمت چپ **ساخت تانل** را بزن.
2. **نقش این سرور:** `ایران (سرور)` را انتخاب کن.
3. **ترنسپورت:** پیشنهاد `nahangx` است. (جدول ترنسپورت‌ها در بخش «آموزش» پنل هست.)
4. **نام (انگلیسی):** یک نام کوتاه مثل `t1`.
5. **IP گوش‌دادن:** `0.0.0.0` را بگذار (یعنی روی همه‌ی IPها گوش بده).
6. **پورت تانل:** پیش‌فرض `3080` است. این پورت را سرور خارج برای وصل شدن استفاده می‌کند.
7. روی **تولید توکن** بزن. توکن باید دقیقاً روی هر دو سرور یکی باشد.
8. **IP مجاز:** IP سرور خارج را بنویس. این مهم‌ترین تنظیم امنیتی است.
9. **پورت‌ها:** پورت‌هایی که کاربر به آن‌ها وصل می‌شود را بنویس. مثلاً:
   - `443` یعنی پورت ۴۴۳ همان‌جا باز شود و به همان پورت برسد.
   - `443=8443` یعنی ورودی ۴۴۳ به پورت ۸۴۴۳ سرور خارج برود.
   - چند پورت را با کاما جدا کن: `443, 2000-2100`
10. روی **ساخت و اجرا** بزن.

### ۶.۲ ساخت تانل روی سرور خارج

راه آسان: کد اتصال

1. در صفحه‌ی **تانل‌ها** روی سرور ایران، دکمه‌ی **کد مقابل** کنار تانل را بزن. کد با `TP1:` شروع می‌شود و کپی می‌شود.
2. در پنل سرور خارج، به صفحه‌ی **ساخت تانل** برو.
3. کد را در کادر **وارد کردن کد از سرور مقابل** بچسبان و **اعمال** را بزن. نقش، ترنسپورت، نام، توکن و پورت خودکار پر می‌شوند.
4. فقط **IP سرور ایران** را در کادر IP بنویس.
5. **ساخت و اجرا** را بزن.

> اگر خواستی به‌جای کد، دستی بسازی: نقش `خارج (کلاینت)` را انتخاب کن، IP سرور ایران، پورت تانل (مثلاً `3080`) و همان توکن را بنویس.

---

## ۷. اتصال دو سرور و بررسی

1. در هر دو پنل، صفحه‌ی **تانل‌ها** را باز کن.
2. وضعیت تانل باید **فعال** یا **وصل** شود. اگر **منتظر اتصال** است، هنوز سرور مقابل وصل نشده.
3. نمودار مسیر هر تانل باید لینک بین دو سرور را **سبز و متحرک** نشان دهد.
4. اگر چیزی درست نبود، دکمه‌ی **لاگ** تانل را بزن.

---

## ۸. اتصال v2ray

تانل فقط ترافیک را جابه‌جا می‌کند. v2ray باید روی سرور خارج اجرا باشد:

1. روی **سرور خارج**، v2ray (Xray یا V2Ray) را نصب و کانفیگ inbound را طوری بساز که روی همان پورتی گوش دهد که در پورت‌های تانل نوشته‌ای (مثلاً `443`). اگر نگاشت `443=8443` داری، v2ray باید روی `8443` باشد.
2. در کلاینت v2ray روی دستگاه یا موبایل:
   - **آدرس (Address):** IP سرور **ایران**
   - **پورت (Port):** پورت ورودی ایران (مثلاً `443`)
   - بقیه‌ی تنظیمات (UUID، پروتکل، TLS و...) همان‌هایی است که در کانفیگ v2ray سرور خارج گذاشته‌ای.

> اگر کاربر به سرور ایران وصل شود و ترافیک برقرار نشود، ابتدا مطمئن شو تانل در هر دو سرور «وصل» است و v2ray روی پورت درست گوش می‌دهد.

## ۹. منوی مدیریت `nahang`

هر وقت خواستی وارد سرور شوی و پنل را مدیریت کنی:

```bash
sudo nahang
```

```
======================================
       Nahang Tunnel Panel Manager
======================================
Panel: active   Version: v1.0.0
  t1               active
--------------------------------------
 1) Panel address and password
 2) Restart panel
 3) Restart a tunnel
 4) Show tunnel logs
 5) Back up tunnels
 6) Check for updates
 7) Update panel
 8) Uninstall completely
 0) Exit
```

| گزینه | کاربرد |
|---|---|
| 1 | آدرس، کاربر و رمز پنل |
| 2 | ری‌استارت کل پنل |
| 3 | ری‌استارت یک تانل |
| 4 | نمایش لاگ یک تانل |
| 5 | ذخیره‌ی پشتیبان از تانل‌ها در `/root` |
| 6 | بررسی نسخه‌ی جدید |
| 7 | به‌روزرسانی پنل |
| 8 | حذف کامل |

## ۱۰. به‌روزرسانی

### با منو (پیشنهادی)

```bash
sudo nahang
```

گزینه‌ی **6** را بزن تا نسخه بررسی شود، سپس گزینه‌ی **7** را بزن و `y` را تایید کن.

### بدون منو

```bash
sudo bash /usr/local/share/tunnelpanel/install.sh --update
```

**توجه:** پورت، IP مجاز، رمز و تانل‌ها حفظ می‌شوند. با این حال قبل از هر به‌روزرسانی، از گزینه‌ی **5** پشتیبان بگیر و روی هر دو سرور به‌روزرسانی کن تا نسخه‌ها یکی بمانند.

---

## ۱۱. پشتیبان‌گیری و بازیابی

- **پشتیبان:** در صفحه‌ی **تنظیمات** → بخش پشتیبان‌گیری، دکمه‌ی **دانلود پشتیبان** را بزن. یا از منو گزینه‌ی **5** را بزن.
- **بازیابی:** در همان بخش، **بازیابی از فایل** را بزن و فایل پشتیبان را انتخاب کن.

> فایل پشتیبان شامل توکن‌هاست. آن را مثل رمز عبور نگه دار.

---

## ۱۲. هشدار تلگرام

اگر تانلی قطع شد یا مدام ری‌استارت شد، پنل پیام می‌فرستد:

1. از **BotFather** در تلگرام یک ربات بساز و **توکن** آن را بگیر.
2. **Chat ID** خودت را بگیر (مثلاً از یک ربات مثل `userinfobot`).
3. در **تنظیمات** → **هشدار تلگرام**، توکن و Chat ID را بگذار و ذخیره کن.
4. با **پیام آزمایشی** مطمئن شو پیام می‌رسد.

---

## ۱۳. حذف کامل

اگر پنل از قبل نصب باشد و دستور نصب را دوباره اجرا کنی، منوی کوتاهی نشان داده می‌شود: نصب مجدد، به‌روزرسانی، یا حذف پنل.

برای حذف مستقیم:

```bash
sudo bash install.sh --uninstall
```


```bash
sudo nahang
```

گزینه‌ی **8** را بزن و `YES` را تایپ کن. پنل، تانل‌ها، تنظیمات و دستور `nahang` پاک می‌شوند.

## ۱۴. عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| تانل **منتظر اتصال** است | توکن، ترنسپورت و پورت تانل را در هر دو سرور مقایسه کن. |
| تانل **قطع** است | ساعت هر دو سرور را با `timedatectl` بررسی کن. برای `nahangx` اختلاف بیشتر از ۲ دقیقه مجاز نیست. |
| پنل باز نمی‌شود | `sudo systemctl status tunnelpanel` را بزن. پنل فقط با SSH در دسترس است؛ مطمئن شو تونل SSH باز است. |
| خطای هش در نصب | فایل‌های Release را دوباره بررسی کن. احتمالاً دانلود ناقص بوده است. |
| نصب دانلود نمی‌کند | مخزن باید **Public** باشد و Release با نام درست منتشر شده باشد. |
| نسخه‌ی جدید دیده نمی‌شود | مطمئن شو Release جدید **Latest** است و Pre-release نیست. |
| رمز را گم کرده‌ای | `sudo nahang` ← گزینه‌ی 1. یا `sudo cat /etc/tunnelpanel/pass` |
| ترافیک کاربر برقرار نیست | تانل را بررسی کن، سپس مطمئن شو v2ray سرور خارج روی همان پورت گوش می‌دهد. |

لاگ هر تانل را با دستور زیر هم می‌توانی ببینی:

```bash
sudo journalctl -u tp-NAME -n 100 --no-pager
```

به‌جای `NAME` نام تانل را بگذار، مثلاً `tp-t1`.

## ۱۵. نکات امنیتی

- **IP مجاز را همیشه پر کن.** بدون آن، پورت تانل برای همه باز است.
- **توکن را محرمانه نگه دار.** هر کسی توکن را داشته باشد می‌تواند به تانل وصل شود. توکن را در گیت‌هاب، چت عمومی یا جای غیرامن قرار نده.
- **رمز پنل را قوی نگه دار** و آن را بین چند نفر پخش نکن.
- **ساعت سرورها را همگام کن:** `sudo timedatectl set-ntp true`
- **به‌روز نگه دار:** هر نسخه‌ی جدید را از منو نصب کن.
- **پورت ۲۲ (SSH)** در بخش پورت‌های قفل‌شونده مجاز نیست، تا دسترسی SSH سرور به‌طور ناخواسته بسته نشود.
