# Nahang Tunnel Panel

راهنمای نصب پنل Nahang Tunnel Panel روی دو سرور لینوکسی.

> ⚠️ فقط روی سرورهایی نصب کن که مالک آن‌ها هستی یا مجاز به مدیریت‌شان هستی.

---

## ۱. پیش‌نیازها

| مورد | توضیح |
|---|---|
| دو سرور لینوکسی | Ubuntu یا Debian با دسترسی `root`؛ یکی در ایران و یکی خارج از ایران |
| آدرس IP عمومی | هر دو سرور باید IP عمومی داشته باشند |

---

## ۲. نصب روی سرور ایران

```bash
curl -fsSL https://raw.githubusercontent.com/Alireza647xvhyfdc/nahangpanel/main/install.sh | sudo bash
```

این دستور نصب‌کننده را از گیت‌هاب می‌گیرد و اجرا می‌کند. باینری پنل هم از Releases همین مخزن دانلود می‌شود.

در حین نصب، پورت پنل پرسیده می‌شود:

- یک پورت بین ۱ تا ۶۵۵۳۵ وارد کن.
- اگر فقط Enter بزنی، یک پورت تصادفی آزاد انتخاب می‌شود.
- پورت‌هایی که در حال استفاده هستند قبول نمی‌شوند.

پورت انتخاب‌شده در پایان نصب نشان داده می‌شود و بعداً هم با منوی `nahang` قابل دیدن است.

### اطلاعات ورود

در پایان نصب، کاربر، رمز و آدرس پنل نمایش داده می‌شود. **رمز را همان‌جا ذخیره کن.** هر زمان لازم شد، با منوی `nahang` (گزینه‌ی ۱) دوباره می‌توانی آن را ببینی.

---

## ۳. نصب روی سرور خارج

همین دستور را روی سرور خارج از ایران اجرا کن:

```bash
curl -fsSL https://raw.githubusercontent.com/Alireza647xvhyfdc/nahangpanel/main/install.sh | sudo bash
```

---

## ۴. ورود به پنل

### با آدرس IP سرور (پیش‌فرض)

در مرورگر باز کن:

```
https://SERVER-IP:PANEL_PORT
```

- گواهی خودامضاست، پس مرورگر هشدار می‌دهد. گزینه‌ی **Advanced ← Proceed** را بزن.
- کاربر: `admin`
- رمز: همان رمزی که در پایان نصب دیدی.

### با SSH (روش جایگزین)

از دستگاه خودت این دستور را اجرا کن و پنجره را باز نگه دار:

```bash
ssh -L PANEL_PORT:127.0.0.1:PANEL_PORT root@SERVER-IP
```

بعد در مرورگر باز کن:

```
http://127.0.0.1:PANEL_PORT
```

> `PANEL_PORT` همان پورتی است که هنگام نصب انتخاب کردی. هر دو جای آن را با همان عدد عوض کن.

---

## ۵. منوی مدیریت `nahang`

بعد از نصب، با این دستور وارد منوی مدیریت می‌شوی:

```bash
sudo nahang
```

```
======================================
       Nahang Tunnel Panel Manager
======================================
Panel: active   Version: v1.0.0
--------------------------------------
 1) Panel address and password
 2) Restart panel
 3) Restart a tunnel
 4) Show tunnel logs
 5) Back up tunnels
 6) Check for updates
 7) Update panel
 8) Uninstall completely
 0) Exit
```

| گزینه | کاربرد |
|---|---|
| 1 | نمایش آدرس، کاربر و رمز پنل |
| 2 | ری‌استارت کل پنل |
| 3 | ری‌استارت یک تانل |
| 4 | نمایش لاگ یک تانل |
| 5 | ذخیره‌ی پشتیبان از تانل‌ها در `/root` |
| 6 | بررسی نسخه‌ی جدید |
| 7 | به‌روزرسانی پنل |
| 8 | حذف کامل |

---

## ۶. به‌روزرسانی

### با منو (پیشنهادی)

```bash
sudo nahang
```

گزینه‌ی **6** را بزن تا نسخه بررسی شود، سپس گزینه‌ی **7** را بزن و `y` را تایید کن.

### بدون منو

```bash
sudo bash /usr/local/share/tunnelpanel/install.sh --update
```

قبل از به‌روزرسانی، از گزینه‌ی **5** پشتیبان بگیر و روی هر دو سرور به‌روزرسانی کن تا نسخه‌ها یکی بمانند.

---

## ۷. حذف کامل

اگر پنل از قبل نصب باشد و دستور نصب را دوباره اجرا کنی، یک منوی کوتاه نشان داده می‌شود: نصب مجدد، به‌روزرسانی، یا حذف پنل.

برای حذف مستقیم:

```bash
sudo bash install.sh --uninstall
```

یا از منوی `nahang` گزینه‌ی **8** را بزن و `YES` را تایپ کن. پنل، تانل‌ها، تنظیمات و دستور `nahang` پاک می‌شوند.

---

## ۸. عیب‌یابی نصب

| مشکل | راه‌حل |
|---|---|
| خطای هش در نصب | فایل‌های Release را دوباره بررسی کن. احتمالاً دانلود ناقص بوده است. |
| نصب دانلود نمی‌کند | مخزن باید **Public** باشد و Release با نام درست منتشر شده باشد. |
| نسخه‌ی جدید دیده نمی‌شود | مطمئن شو Release جدید **Latest** است و Pre-release نیست. |
| پنل باز نمی‌شود | `sudo systemctl status tunnelpanel` را بزن. |
| رمز را گم کرده‌ای | `sudo nahang` و گزینه‌ی ۱ را بزن، یا `sudo cat /etc/tunnelpanel/pass` را اجرا کن. |

---

## ۹. نکته‌ی امنیتی

رمز پنل را قوی نگه دار و آن را بین چند نفر پخش نکن. ساعت هر دو سرور را هم با `sudo timedatectl set-ntp true` همگام کن.
